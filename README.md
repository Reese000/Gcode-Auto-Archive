# Fusion 360 G-Code Auto-Archive System

Automatically archives G-code files (.nc) generated by Fusion 360 with real-time system tray monitoring, Windows auto-start, and robust error handling.

## Features

- **Custom Tray Icon**: Blue folder with white gear symbol representing archiving
- **Right-click Menu**: Quick access to status, open archive folder, toggle auto-start, start/stop, exit
- **Real-time Monitoring**: Event-driven file detection with 1-second polling fallback
- **Metadata Extraction**: Parses G-code for program name, post version, tools used
- **Organized Archive**: Files stored in `gcode_archive_all\YYYY\MM\DD\` with descriptive names
- **Auto-start Option**: Launches automatically when you log into Windows (hidden, no console)
- **Drive Handling**: Auto-detects USB drives (Fixed/Removable) and monitors all available drives
- **Robust Copy**: Retries up to 3 times if G-code file is locked by Fusion 360
- **Thread-Safe**: Uses lock mechanisms to prevent race conditions in file tracking

## Installation

1. **Quick Start** (temporary):
   - Double-click `Start-TrayApp.vbs` to launch the watcher
   - Check system tray for the blue folder-with-gear icon

2. **Install with Auto-start** (permanent):
   - Double-click `Install-Watcher.bat`
   - This registers the app to start automatically on login
   - The app will start immediately

3. **Uninstall**:
   - Double-click `Uninstall-Watcher.bat`
   - This removes auto-start registration and config file

## How It Works

1. **File Detection**: When Fusion 360 generates G-code (typically `1001.nc`), it's written to the active drive/directory
2. **Metadata Extraction**: The script reads the first 50 lines to extract:
   - Program name (e.g., `O01001`)
   - Post processor version and modification date
   - Tool numbers used (from `T# D#` lines)
3. **Archiving**: The file is copied to the archive directory with a descriptive name:
   ```
   2025-04-04_10-30-00_O01001_post_v2_1_tools_11_12_13.nc
   ```
4. **Tracking**: The system remembers which files it has already archived to avoid duplicates
5. **Notification**: System tray balloon tip shows the archive operation

## System Tray Icon

The tray icon displays:
- Blue folder with white gear (always)
- Tooltip text: "G-Code Archive Watcher"
- Status line shows "Watching" or "Stopped" and total archived count

**Right-click menu options**:
- `Show Status` - Display detailed information
- `Open Archive Folder` - Browse archived G-code files
- `Watch All Drives: ON/OFF` - Toggle between watching all drives or a single folder
- `Auto-Start: ON/OFF` - Toggle auto-start registration
- `Change Watch Folder...` - Select folder when Watch All Drives is OFF
- `Start Watching` / `Stop Watching` - Control file monitoring
- `Exit` - Quit the application

## Archive Structure

```
gcode_archive_all/
├── 2025/
│   ├── 10/
│   │   ├── 25/
│   │   │   ├── 2025-10-25_14-30-00_O01001_post_v2_1_tools_11_12_13_14_16_20_21_24_25_3_4_5_7.nc
│   │   │   ├── 2025-10-25_15-45-22_O01002_post_v2_1_tools_4_5_6.nc
│   │   │   └── archive_log.csv
```

The `archive_log.csv` records all archive operations with timestamps, source filenames, destination paths, program names, and tools.

## Configuration

Configuration is stored in `%APPDATA%\GcodeArchiveWatcher\config.xml`:

```xml
<configuration>
  <WatchPath>C:\</WatchPath>
  <WatchAllDrives>true</WatchAllDrives>
  <ArchiveRoot>gcode_archive</ArchiveRoot>
  <AutoStart>true</AutoStart>
</configuration>
```

Settings can be changed via the tray icon context menu:
- Toggle Auto-Start on/off
- Toggle Watch All Drives on/off
- Change Watch Folder (when Watch All Drives is OFF)

## Technical Details

- **Polling Interval**: 1 second for file system checks, 60 seconds for new drive detection
- **File Filter**: `*.nc` (G-code files)
- **Metadata Parsing**: Reads first 50 lines to extract comments and headers
- **Copy Retry**: 3 attempts with 500ms delay (handles Fusion's file locking)
- **Watch Modes**:
  - **All Drives**: Monitors all Fixed and Removable drives (C:\, D:\, etc.)
  - **Single Folder**: Monitors a specific directory (configurable)

## Troubleshooting

**Tray icon not appearing**: Check Task Manager for `powershell.exe` processes. Launch `Start-TrayApp.vbs` manually.

**No files being archived**: Right-click icon → Show Status to verify watch mode and paths. Ensure G-code is being generated to a monitored location.

**Auto-start not working**: Re-run `Install-Watcher.bat` as Administrator. Check Startup folder: `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\`

**Archive folder empty**: The watcher only archives files created *after* it starts. Generate new G-code or restart the watcher.

**Drive not detected**: In "Watch All Drives" mode, only Fixed and Removable drives are monitored. Network drives are excluded.

## Notes

- **Original files are preserved**: Your Fusion 360 output remains untouched; only a copy is archived
- **Overwrites handled**: If Fusion overwrites `1001.nc`, the archived version already has a unique timestamped name
- **Low overhead**: Runs quietly in system tray with minimal CPU/memory usage
- **Exit gracefully**: Use tray icon menu → Exit to stop monitoring cleanly
